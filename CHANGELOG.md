## 0.1.0

- Add `@napi` exports for synchronous Dart functions.
- Generate real Wasm Node-API bridges and a scoped JavaScript runtime.
- Build importable Node/browser ESM packages with TypeScript declarations.
- Support booleans, safe integers, doubles, UTF-16 strings, copied bytes, and nullable values.
- Validate signatures, argument counts, types, integer precision, and output ownership.
- Use Dart 3.13.5 experimental Wasm interop; no native addons or npm runtime dependencies.
